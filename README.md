## GitHub Pages

Sube el contenido de esta carpeta a la raíz de tu repositorio. En **Settings → Pages**, selecciona **Deploy from a branch**, la rama `main` y la carpeta `/(root)`. Guarda la configuración. GitHub mostrará el enlace cuando termine el despliegue.
